# UXUI.md — 책표지 리뷰 큐레이션 서비스 (스켈레톤 MVP)

관련 문서: [PRD.md](./PRD.md), [TRD.md](./TRD.md)

TRD의 플로우(업로드 → 인식 → 알라딘 조회 → 결과 표시/저장 → 목록 조회)를 화면 단위로 쪼개 각 단계의 와이어프레임과 Tailwind 스타일 가이드를 정의한다.

---

## 0. 디자인 원칙

- **모노톤**: 색상은 Tailwind `neutral`/`zinc` 그레이스케일만 사용. 포인트 컬러 없음(강조가 필요한 최소한의 곳에만 순검정/순백 대비 사용).
- **금지**: glassmorphism(반투명+블러), 그라데이션(`bg-gradient-*`) 일체 금지. 배경/카드/버튼 모두 단색(flat) 처리.
- **여백 중심**: 장식 대신 넉넉한 여백과 타이포 위계로 정돈된 느낌을 낸다.
- **테두리/그림자**: 그림자는 `shadow-sm` 이하로만 최소 사용, 주로 `border border-neutral-200`으로 구획을 나눈다.
- **다크모드**: 스켈레톤 범위에는 포함하지 않음(추후 검토).

### 컬러 팔레트 (Tailwind 토큰)

| 용도 | 클래스 | 비고 |
|---|---|---|
| 페이지 배경 | `bg-neutral-50` | |
| 카드/패널 배경 | `bg-white` | |
| 기본 텍스트 | `text-neutral-900` | |
| 보조 텍스트 | `text-neutral-500` | |
| 테두리 | `border-neutral-200` | |
| 구분선 | `divide-neutral-200` | |
| Primary 버튼 | `bg-neutral-900 text-white hover:bg-neutral-800` | 그라데이션 없이 단색 |
| Secondary 버튼 | `border border-neutral-300 text-neutral-900 hover:bg-neutral-100` | |
| 비활성 | `bg-neutral-100 text-neutral-400` | |
| 에러 텍스트 | `text-red-600` (에러 강조에 한해 유일하게 허용되는 유채색) | |
| 별점 채움 | `text-neutral-900` / 빈 별 `text-neutral-300` | |

### 타이포그래피

| 요소 | 클래스 |
|---|---|
| 페이지 타이틀 | `text-2xl font-semibold text-neutral-900` |
| 섹션 타이틀 | `text-lg font-medium text-neutral-900` |
| 본문 | `text-sm text-neutral-700` |
| 캡션/메타 | `text-xs text-neutral-500` |

### 공통 컴포넌트

- **버튼**: `rounded-md px-4 py-2 text-sm font-medium transition-colors` + 위 컬러 표
- **카드**: `rounded-lg border border-neutral-200 bg-white p-4`
- **배지(카테고리 태그)**: `rounded-full border border-neutral-300 px-2.5 py-0.5 text-xs text-neutral-600`
- **상단 네비게이션**: 모든 화면 공통, `border-b border-neutral-200 bg-white`, 좌측 로고/서비스명(`text-base font-semibold`), 우측 "목록" ↔ "업로드" 이동 링크

## 1. 업로드 화면 (`app/page.tsx`)

표지 사진을 업로드하는 진입 화면. 빈 상태(Empty) / 이미지 선택 후(Selected) 두 가지 상태를 가진다.

### 1-1. Empty 상태

```
┌──────────────────────────────────────────────┐
│  📚 표지리뷰            [내 목록 →]            │  ← 상단 네비 (border-b)
├──────────────────────────────────────────────┤
│                                                │
│            표지 사진을 업로드하세요              │  ← text-2xl font-semibold
│      찍어둔 책 표지로 리뷰와 평점을 바로 확인       │  ← text-sm text-neutral-500
│                                                │
│   ┌────────────────────────────────────┐      │
│   │                                      │     │
│   │     ⬆  이미지를 드래그하거나          │      │  ← border-2 border-dashed
│   │       클릭해서 업로드                 │     │     border-neutral-300
│   │       JPG / PNG, 최대 10MB           │      │     rounded-lg, bg-white
│   │                                      │     │
│   └────────────────────────────────────┘      │
│                                                │
└──────────────────────────────────────────────┘
```

- 드롭존: `border-2 border-dashed border-neutral-300 rounded-lg bg-white flex flex-col items-center justify-center py-16 hover:border-neutral-400 cursor-pointer`
- 아이콘은 outline 스타일 단색 아이콘(예: lucide `Upload`) `text-neutral-400`
- 드래그 오버 시 `border-neutral-900 bg-neutral-50`로만 변화(그라데이션 없이)

### 1-2. Selected 상태 (업로드 전 미리보기)

```
┌──────────────────────────────────────────────┐
│  📚 표지리뷰            [내 목록 →]            │
├──────────────────────────────────────────────┤
│         ┌──────────────┐                     │
│         │              │   선택한 이미지         │
│         │  [표지 미리보기]│   cover.jpg · 2.1MB  │
│         │              │                      │
│         └──────────────┘                     │
│                                                │
│   [다시 선택]              [이 책 식별하기 →]     │  ← Secondary / Primary
│                                                │
└──────────────────────────────────────────────┘
```

- 미리보기 이미지: `w-40 aspect-[3/4] object-cover rounded-md border border-neutral-200`
- 버튼 행: `flex justify-end gap-2`

## 2. 인식 중 상태 (동일 페이지 내 상태 전환, 별도 라우트 아님)

업로드 버튼 클릭 시 `/api/identify → /api/aladin/search → /api/aladin/lookup`이 순차 진행되는 동안 보여줄 로딩 상태. 3단계를 체크리스트 형태로 보여줘 "지금 뭘 하고 있는지" 인지시킨다.

```
┌──────────────────────────────────────────────┐
│  📚 표지리뷰                                    │
├──────────────────────────────────────────────┤
│         ┌──────────────┐                     │
│         │ [표지 미리보기]  │                     │
│         └──────────────┘                     │
│                                                │
│   ✓  표지에서 제목·저자 인식 완료                 │  ← 완료: text-neutral-900
│   ●  알라딘에서 도서 검색 중...                  │  ← 진행중: 스피너 + text-neutral-900
│   ○  상세정보 · 리뷰 불러오는 중                  │  ← 대기: text-neutral-400
│                                                │
└──────────────────────────────────────────────┘
```

- 스피너: 회전 애니메이션의 단색 원(`animate-spin border-2 border-neutral-300 border-t-neutral-900`), 별도 색 없음
- 체크(✓)는 `text-neutral-900`, 대기 아이콘(○)은 `text-neutral-300`
- 그라데이션 프로그레스바 대신 위와 같은 단계 리스트 사용

## 3. 결과 화면 (인식·저장 완료, 동일 페이지 내 상태 전환)

인식이 끝나면 알라딘 상세정보를 보여주고, 이 시점에 자동으로 Supabase에 저장(POST `/api/books`)된 뒤 저장 완료 표시를 함께 노출한다.

```
┌──────────────────────────────────────────────┐
│  📚 표지리뷰            [내 목록 →]            │
├──────────────────────────────────────────────┤
│  ┌────────┐  소설의 감정                        │  ← text-lg font-medium
│  │ [표지] │  김OO 지음                          │  ← text-sm text-neutral-500
│  │ 이미지  │                                    │
│  │        │  ★★★★☆  9.2  (알라딘 리뷰 128건)     │  ← 별점 text-neutral-900/300
│  └────────┘  ⟨소설/시/희곡⟩                      │  ← 카테고리 배지
│                                                │
│              ✓ 내 목록에 저장됨                  │  ← text-xs text-neutral-500
│                                                │
│  ──────────────────────────────────────────  │  ← divide-neutral-200
│  알라딘 리뷰                                     │  ← text-lg font-medium
│  ┌────────────────────────────────────────┐   │
│  │ ★★★★★  "문장이 좋아서 계속 곱씹게 됨"      │   │  ← 카드, border-neutral-200
│  │ ★★★☆☆  "중반부가 조금 늘어지는 느낌"       │   │
│  │ ★★★★★  "올해 읽은 소설 중 최고"           │   │
│  └────────────────────────────────────────┘   │
│                                                │
│  다른 서점에서도 보기                             │  ← text-sm font-medium
│  [교보문고에서 검색 →]   [YES24에서 검색 →]        │  ← Secondary 버튼, 외부 링크
│                                                │
│  [다른 표지 업로드하기]                           │  ← Secondary, 전체 폭
└──────────────────────────────────────────────┘
```

- 표지 썸네일: `w-24 aspect-[3/4] object-cover rounded-md border border-neutral-200`
- 별점: 채워진 별 `text-neutral-900`, 빈 별 `text-neutral-300`, 숫자 평점은 옆에 `text-sm text-neutral-500`
- 리뷰 카드 리스트: `divide-y divide-neutral-200` 안에 각 리뷰 `py-3`, 리뷰 텍스트 `text-sm text-neutral-700`, 2줄 초과 시 `line-clamp-2`
- 교보/YES24 버튼: 외부 이동 아이콘(↗) 포함, 클릭 시 `target=_blank`
- "저장됨" 표시는 별도 배너 없이 텍스트 한 줄로 조용히 처리(모노톤 원칙)

## 4. 에러 상태 (동일 페이지 내, 단계별 실패 지점에 따라 메시지만 교체)

TRD 6절 에러 정책을 화면으로 매핑. 카드형 알림 하나로 통일하고, 실패 지점에 따라 문구만 바뀐다.

```
┌──────────────────────────────────────────────┐
│  📚 표지리뷰                                    │
├──────────────────────────────────────────────┤
│         ┌──────────────┐                     │
│         │ [표지 미리보기]  │                     │
│         └──────────────┘                     │
│                                                │
│   ⚠ 표지를 인식하지 못했어요                     │  ← text-red-600, 아이콘도 동일색
│      다른 각도로 찍은 사진으로 다시 시도해보세요    │  ← text-sm text-neutral-500
│                                                │
│   [다시 시도]              [다른 사진 선택]        │
│                                                │
└──────────────────────────────────────────────┘
```

케이스별 문구:
| 실패 지점 | 문구 |
|---|---|
| Vision LLM 인식 실패 | "표지를 인식하지 못했어요 · 다른 각도로 찍은 사진으로 다시 시도해보세요" |
| 알라딘 검색 0건 | "알라딘에서 이 책을 찾지 못했어요 · 제목이 잘 보이는 사진으로 다시 시도해보세요" |
| API 호출 실패(네트워크 등) | "일시적인 오류가 발생했어요 · 잠시 후 다시 시도해주세요" |

- 알림 카드: `rounded-lg border border-red-200 bg-white p-4`, 아이콘/텍스트만 `text-red-600`, 배경은 흰색 유지(그라데이션·톤 배경 금지)
- 버튼 두 개는 결과 화면과 동일한 Secondary 스타일

## 5. 목록 화면 (`app/books/page.tsx`)

저장된 책을 알라딘 `categoryName` 기준으로 그룹핑해서 보여준다.

### 5-1. 데이터가 있을 때

```
┌──────────────────────────────────────────────┐
│  📚 표지리뷰            [+ 새로 업로드]          │
├──────────────────────────────────────────────┤
│  내 책 목록 (12)                                │  ← text-2xl font-semibold
│                                                │
│  소설/시/희곡 (5)                                │  ← text-lg font-medium, 구분선
│  ┌────────┐ ┌────────┐ ┌────────┐             │
│  │ [표지] │ │ [표지] │ │ [표지] │  ...          │  ← 카드 그리드
│  │ 제목    │ │ 제목    │ │ 제목    │             │
│  │ ★4.6   │ │ ★4.2   │ │ ★4.8   │             │
│  └────────┘ └────────┘ └────────┘             │
│                                                │
│  인문/에세이 (4)                                 │
│  ┌────────┐ ┌────────┐ ...                    │
│  │        │ │        │                        │
│  └────────┘ └────────┘                        │
│                                                │
│  경제/경영 (3)                                   │
│  ┌────────┐ ...                                │
│                                                │
└──────────────────────────────────────────────┘
```

- 카테고리 섹션: 카테고리명 `text-lg font-medium` + 개수, 아래 `grid grid-cols-2 sm:grid-cols-4 lg:grid-cols-6 gap-4`
- 책 카드: `rounded-lg border border-neutral-200 bg-white p-2 hover:border-neutral-400 cursor-pointer` → 클릭 시 결과 화면(3번)과 동일한 상세 뷰를 모달 또는 상세 페이지로 재사용
- 카드 내부: 표지(`aspect-[3/4] object-cover rounded`), 제목(`text-sm font-medium truncate`), 평점(`text-xs text-neutral-500`)
- 카테고리 정렬 기준: 저장된 책이 많은 순(스켈레톤 단순 규칙)

### 5-2. Empty 상태 (저장된 책이 없을 때)

```
┌──────────────────────────────────────────────┐
│  📚 표지리뷰            [+ 새로 업로드]          │
├──────────────────────────────────────────────┤
│                                                │
│         아직 저장된 책이 없어요                   │  ← text-lg font-medium
│      표지 사진을 업로드하면 여기에 쌓여요           │  ← text-sm text-neutral-500
│                                                │
│              [표지 업로드하러 가기]               │  ← Primary 버튼
│                                                │
└──────────────────────────────────────────────┘
```

## 6. 화면 흐름 요약

```
[업로드(Empty)] → 이미지 선택 → [업로드(Selected)]
        └─ "이 책 식별하기" 클릭 → [인식 중]
                 ├─ 성공 → [결과 화면] → "내 목록에 저장됨" 자동 표시
                 │            ├─ [교보/YES24 링크] → 새 탭 이동
                 │            └─ [다른 표지 업로드하기] → 업로드(Empty)로 복귀
                 └─ 실패 → [에러 상태] → "다시 시도" / "다른 사진 선택"

[내 목록] ⇄ [업로드] : 상단 네비게이션으로 상시 이동 가능
[내 목록] 카드 클릭 → 저장된 책의 상세(결과 화면과 동일 레이아웃, 저장 배너 없이 표시)
```

## 7. 반응형 규칙 (스켈레톤 최소 기준)

- 모바일 우선: 업로드/결과/에러 화면은 `max-w-md mx-auto` 단일 컬럼 고정
- 목록 화면 그리드만 `grid-cols-2`(모바일) → `sm:grid-cols-4` → `lg:grid-cols-6`으로 반응형 확장
- 별도 데스크톱 전용 레이아웃(사이드바 등)은 범위 밖

## 8. 스켈레톤 범위 밖 UI (참고, TRD 7절과 동일)

- 다중 후보 선택 화면(알라딘 검색 결과가 여러 건일 때 리스트에서 고르는 UI)
- 로그인/회원가입 화면
- 리뷰 원문 전체보기, 필터/정렬 UI
- 다크모드
