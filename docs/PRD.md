# PRD — 책표지 리뷰 큐레이션 서비스 (스켈레톤 MVP)

## 1. 문제 정의

서점 가판대에서 표지가 마음에 들거나 관심 가는 주제의 책을 발견하면 사진을 찍어두지만, 집에 돌아온 뒤 그 책을 다시 찾아 별점·리뷰를 확인하고 구매를 결정하는 과정이 번거로워 결국 방치하게 된다. 사진만 쌓이고 실제 검토·구매로 이어지지 않는 것이 핵심 문제.

## 2. 목표

표지 사진을 업로드하면 자동으로 어떤 책인지 식별하고, 리뷰/평점 정보와 카테고리(토픽)를 함께 보여줘서, "찍기만 하고 잊어버리는" 흐름을 "찍으면 바로 정리되는" 흐름으로 바꾼다.

## 3. 타겟 사용자

1차 타겟은 본인(단일 사용자). 로그인 없이 바로 쓸 수 있는 개인용 도구로 시작.

## 4. 핵심 사용자 플로우

1. 사용자가 웹에서 책 표지 사진을 업로드한다(파일 선택 또는, 모바일에서는 카메라로 바로 촬영).
2. 시스템이 사진에서 제목/저자를 자동 인식한다.
3. 인식된 정보로 알라딘에서 해당 책을 찾아 상세정보·평점·리뷰·카테고리를 가져온다.
4. 결과 화면에 표지 이미지, 제목/저자, 알라딘 평점·리뷰, 카테고리(토픽)가 표시된다.
5. 결과는 자동으로 목록에 저장되어, 이후 재방문 시 다시 확인할 수 있다.
6. 목록 화면에서는 책을 카테고리(토픽)별로 묶어서 볼 수 있다.
7. 교보문고/YES24에서도 확인하고 싶다면, 해당 사이트의 검색 결과 페이지로 바로 이동할 수 있는 링크를 제공한다.

## 5. 스코프

### In Scope (스켈레톤 MVP)
- Next.js 기반 웹앱에서 이미지 업로드 — 파일 선택/드래그앤드롭 외에, 모바일 브라우저에서는 `<input capture="environment">`로 후면 카메라 즉시 촬영 지원
- Vision LLM을 이용한 표지 사진 → 제목/저자 자동 인식 (단일 호출)
- 알라딘 Open API를 통한 도서 검색(ISBN 확보) 및 상세조회(평점·리뷰·카테고리)
- 검색 결과가 여러 건이어도 최상위 1건을 자동으로 채택
- 알라딘이 제공하는 카테고리(categoryName)를 그대로 사용한 토픽 분류
- 교보문고/YES24는 리뷰 데이터 없이, 검색 결과 페이지로 이동하는 아웃바운드 링크만 제공
- Supabase(Postgres)에 업로드 이력 영속 저장
- 저장된 책 목록을 카테고리별로 그룹핑해서 보여주는 목록 화면

### Out of Scope (이번 스켈레톤에서 제외, 추후 검토)
- 로그인/인증 (Supabase Auth) — 스키마만 대비, 기능은 미구현
- 교보문고/YES24 리뷰 스크래핑
- 여러 후보 도서 중 사용자가 직접 선택하는 UI
- GCP OCR 등 대체/보조 인식 엔진 (Vision LLM 실패 시 폴백)
- 자체 LLM 기반 토픽 재분류 로직
- 다중 사용자 지원, 공유 기능

## 6. 성공 기준

- 표지 사진을 업로드하면 몇 초 내에 제목/저자가 인식되고, 알라딘 기반 평점·리뷰·카테고리가 화면에 표시된다.
- 업로드한 책이 Supabase에 저장되어, 페이지를 새로고침하거나 재방문해도 목록에서 다시 확인할 수 있다.
- 목록 화면에서 카테고리별로 책이 구분되어 보인다.
- 인식에 실패하거나 알라딘에서 매칭되는 책을 찾지 못한 경우, 사용자에게 실패 사실이 명확히 안내된다.

## 7. 리스크 및 가정

- Vision LLM의 표지 인식 정확도가 완벽하지 않을 수 있음 (특수 폰트, 반사광, 부분 가림 등). 스켈레톤 단계에서는 이를 허용하고 추후 개선.
- 알라딘 API가 모든 도서(특히 절판/희귀 도서)를 커버하지 못할 수 있음 — 매칭 실패 시 사용자에게 안내.
- 교보문고/YES24는 링크만 제공하므로 해당 사이트의 실제 리뷰 내용은 서비스 내에서 볼 수 없음(사용자가 직접 이동해서 확인).
